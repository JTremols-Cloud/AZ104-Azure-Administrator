# AZ-104 Azure Administrator Journey

This repository documents my hands-on Azure labs built around a fictional MSP engagement, created while preparing for the **AZ-104: Microsoft Azure Administrator** exam.

> **Scenario:** Tremols Tech, an early-stage Managed Service Provider (MSP), is onboarding **ClearView Dental Associates**, a fictional dental group with multiple clinics and ~180 staff, into Microsoft Azure. ClearView and all names, accounts, and data in this repo are fictional. Labs are based on Microsoft's AZ-104 learning content.

## ☁️ What each lab covers

**Lab 01: Identity & Governance** ✅
- Entra ID users, guests, and groups · Management groups · RBAC and custom roles · Azure Policy · Tagging · Resource locks

###### Outcome: a secure identity and governance baseline that later resources inherit.

**Lab 02: Storage & Backup** 🔜
- Storage accounts · Blob Storage and Azure Files · Lifecycle management · Recovery Services vaults · Azure Backup

**Lab 03: Networking & Connectivity** 🔜
- VNets and subnets · NSGs · VNet peering · VPN gateways · Private endpoints · Load balancers · DNS

**Lab 04: Compute & Virtual Machines** 🔜
- VMs and Availability Zones · VM Scale Sets · ARM templates and Bicep · App Service · Container Instances and Container Apps

**Lab 05: Analytics & Logs** 🔜
- Azure Monitor · Log Analytics · Alerts · Diagnostic settings · Workbooks · KQL

## 🔧 How each lab is structured

- Business scenario
- Step-by-step walkthrough (Portal, plus PowerShell/CLI/IaC where they apply)
- Results, challenges, and what I learned
- Screenshots (redacted of IDs and emails)
- Cleanup steps
